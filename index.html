PACKAGE SPECIFICATION / YUNA

YUNA (v1.0.0)

com.frosty.yuna • Section: Tweaks

Yuna solves the problem of clumsy clipboard management on iOS by embedding a dedicated trigger button straight into the native keyboard dock (UIKeyboardDockView).

Dock IntegrationDedicated button beside dictation or emoji with configurable position
Content TypesPlain text, rich URLs, images (PNG/JPEG with downsampling), file URLs
Pinning SystemPin vital snippets to top; pinned items are never pruned on eviction
Row Layouts1, 2, 3, or 4 rows of cards dynamically computed for keyboard space
Direct InsertionInserts text directly into active responder via UIKeyboardImpl
Daemon ProcessSpringBoard pasteboard listener daemon (YunaServer) with change-count throttling
Open in Sileo Download .deb
Target PlatformiOS 15.0 – 16.x+ (Rootless)
Architecturesarm64 & arm64e (Dual-slice fat binary)
PAC ComplianceTrampoline hooks via ElleKit (zero naked vtable pointer swaps)
Rootless Prefix/var/jb (JBROOT_PATH)
Preferences Path/var/mobile/Library/Preferences/com.frosty.yuna.plist
History Storage/var/jb/Library/Application Support/Yuna/history.plist
Dependenciesmobilesubstrate (>= 0.9.5000), ellekit, preferenceloader
